# Model Components

These files are compact academic samples of the method:

- `adaptive_router.py`: question-conditioned scoring, adaptive top-k selection, and weighted evidence aggregation.
- `grounded_router.py`: question-to-video grounding before routing.
- `context_fusion.py`: optional auxiliary-context fusion.

They intentionally omit the complete backbone, dataset loader, checkpointing, and experiment-specific implementation.
