# Paper Scope

The accompanying paper studies whether adaptive temporal routing selects useful video evidence or learns shortcuts.

The analysis compares four adaptive conditions:

1. Collapse-prone routing with context.
2. Anti-collapse routing with context.
3. Anti-collapse routing without context.
4. Question-grounded anti-collapse routing without context.

The repository exposes the central method samples and the diagnostic protocol. It does not expose the complete training implementation or raw routing records.
