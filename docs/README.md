# Paper scope

The accompanying paper asks whether adaptive temporal routing selects useful video evidence. It compares four adaptive routers on MSRVTT-QA with a uniform-pooling reference (M2) taken from a companion manuscript:

1. Collapse-prone routing with context.
2. Anti-collapse routing with context.
3. Anti-collapse routing without context.
4. Question-grounded anti-collapse routing without context.

This repository provides the router, objectives, and diagnostics used in the experiments, with aggregate results and figures. The complete training code and the per-question records are available from the corresponding author on reasonable request.
